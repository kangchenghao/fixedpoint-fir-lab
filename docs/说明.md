# 定点 FIR：把误差来源拆开看

**项目主导：kangchenghaokang-dot。**我发起并持续推进相关研究探索，明确资源约束，并推动工作形成轻量、可复现的公开作品。研究动机、方向与范围取舍属于我的项目主导工作；具体代码、测试和运行采用AI协作，详见[贡献分工](../CONTRIBUTIONS.md)。

这个作品用标准 FIR 滤波展示数值实验方法。输入是本项目生成的正弦波和固定种子噪声，没有真实脑电、受试者或临床验证，也不主张新算法。

在仓库目录运行 `python tools/check.py`，即可执行测试并重新生成 `results/demo.json` 和合成输入。只用 Python 3.10+ 标准库，不下载工具。仅运行实验可用 `python run.py experiment --output results/demo.json`。若直接使用 `python -m fixedpoint_fir_lab experiment --output results/demo.json`，先按英文 README 把本仓库 `src` 加到当前进程的 PYTHONPATH。

滤波器为 160 Hz 采样、31 tap、8–30 Hz Hamming 窗带通，在 19 Hz 归一化。8/30 Hz 是过渡带切点，幅度约一半。群延迟 15 点即 93.75 ms，是信号延迟，不是硬件算多久。

输入乘 4、系数乘 32768，均按 ties-to-even 量化。输入须落在有符号 14 位范围，越界拒绝。输出右移 15/13/11 位后，每个整数单位分别是 1/4、1/16、1/64 uV；先还原单位，再比较误差。负数右移向负无穷取整，会产生负偏差。

每段 512 点完整卷积得到 542 点，包含零初态启动和末尾响应，误差统计不删除暂态。报告依次区分输入、系数、输出量化的增量误差，以及最终总误差；各阶段 RMSE 不能简单相加。

实际默认实验中，小幅度输入的总 NRMSE 从 shift15 的 3.8337% 降到 shift13 的 0.9662%、shift11 的 0.2423%。小幅度案例特意位于 1/4 uV 网格，输入量化误差为零，目的是隔离输出精度；这不是随机挑选的真实数据或独立留出验证。1% 只是展示用参考线。

直接计算与对称配对的整数输出逐项相同。保守界为 `8192*sum(abs(coef))=389455872<2^31`，并用 32 位检查器逐部分和检查。测试还注入正／负溢出、错误输出和漏尾部，确认这些错误被拒绝。Python 的任意精度计算不是 FPGA 或 CPU 的性能模型。

值得展示的是：先写清合同，使用独立计算路径，保留失败，区分量化阶段和单位，再提供可重复运行的证据。更细输出通常减少最后一步误差，但不能消除之前的误差，也不能直接推广到其他信号。
