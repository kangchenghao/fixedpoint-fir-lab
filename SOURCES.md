# Sources and provenance

This implementation was written for this standalone laboratory from the stated mathematical formula. It does not copy a prior private project, third-party source code, EEG files, CPU RTL, external plots or paper figures. All supplied signals are generated by `make_fixtures()` in the executing package.

- [SciPy `firwin` documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.firwin.html): background for the standard window method, cutoff interpretation and passband gain normalization. SciPy is neither imported nor used to validate this repository.
- [Python `round`](https://docs.python.org/3/library/functions.html#round): ties-to-even behavior. Input and coefficient quantization use this rule.
- [Python integer bitwise operations](https://docs.python.org/3/library/stdtypes.html#bitwise-operations-on-integer-types): arithmetic right-shift semantics.

The authors of cited sources retain their rights. No external data license is needed for these newly generated synthetic samples. The repository's MIT license covers its own code and documentation, not the linked websites. AI assistance is described separately in `AI_USAGE.md`.

The checked-in report records executing package-file hashes and the canonical JSON hash of its synthetic fixture. Hashes support traceability; they are not evidence of biological validity, novelty or independent human authorship.
